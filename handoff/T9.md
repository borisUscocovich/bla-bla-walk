# T9 handoff: checked walking alternatives

## Status

Implementation is prepared on `feat/t9-checked-walking-routes`, based on the T1 map foundation and current `main`. T1 is not yet merged to `main`, so this branch depends on that foundation. The route snapshot and adapter acceptance checks pass; full route eligibility remains unknown until per-segment access and T10 coverage are checked.

## Limits

The route graph build timestamp is not exposed by the provider. `snapshot_date` is the date these routes were retrieved, not a graph version. Router duration is retained in the source snapshot for audit only; the app duration comes from T2's configured walking speed.
